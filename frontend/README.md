## 1. Overview & Objectives

The NASA-FLAME frontend is a dedicated scientific research and simulation interface modeling the physical dynamics of flames in microgravity (0g) versus terrestrial (1g) and partial gravity (Lunar 0.166g / Martian 0.38g).

Flames in microgravity behave fundamentally differently than on Earth:
- **Buoyancy Suppression ($Gr \approx 0$)**: Natural convection ceases; hot gases do not rise.
- **Burke-Schumann Regime**: Flames assume a radially symmetric spherical geometry dictated strictly by molecular diffusion.
- **Soot Aggregation**: Soot particles linger in an outer shell rather than venting upward, altering emissivity.
- **Radiative Extinction**: Accumulation of combustion products ($CO_2$, $H_2O$) triggers radiative quenching at low flow rates.

This platform provides interactive modeling, 2D temperature contour visualization, transient time-series trajectory plotting, dimensionless scaling metrics, and AI-driven scientific analysis.

## 3. Implemented Pages & Capabilities

### 1. Landing Page (`/`)
- **Mission Branding**: Clean scientific header and mission hooks.
- **Interactive Gravity Switcher**: Live preview of flame geometry transitions across 0g, 0.166g, 0.38g, and 1.0g.
- **Physical Principles Grid**: Burke-Schumann diffusion, buoyancy elimination, soot stagnation, and radiative extinction limits.
- **Spaceflight Benchmarks**: ISS CIR/ACME, Glenn 2.2-Second Drop Tower, and Artemis lunar analogues.

### 2. Research Dashboard (`/dashboard`)
- **Live System Telemetry**: Real-time FastAPI connectivity verification (`/health`), database engine status, and latency.
- **Scientific Stat Cards**: Total experiments, simulation runs, microgravity ratio, and partial-g breakdowns.
- **Gravity Condition Selector**: Visualizer and physical breakdown of Grashof ($Gr$) and Richardson ($Ri$) impacts.
- **Live Experiment Feed**: Instant table of saved experiments with direct simulation trigger shortcuts.

### 3. Experiment Workspace (`/workspace`)
- **NASA Flight Templates**: Instant pre-configuration for ISS ACME Methane, Drop Tower Heptane Droplet, Artemis Lunar 0.166g, Martian 0.38g, and Terrestrial 1g Plume.
- **Reactant & Chamber Controls**: Fuel species (Methane, Propane, Heptane, Hydrogen, Ethylene), flow rate ($sccm$), ambient $O_2$ percentage ($5-100\%$), pressure ($0.1-50\text{ atm}$), burner/droplet diameter ($mm$), ambient temperature ($K$).
- **Numerical Solver Settings**: Physical duration ($s$), time step delta ($\Delta t$), grid points ($32\times32$ to $128\times128$), and optically thin radiation model toggle.
- **One-Click Execution**: Dispatches `POST /api/simulations/run` and `POST /api/analysis/run` with live elapsed solver duration telemetry.

### 4. Simulation Results & Comparator (`/simulations`)
- **Quantitative Scalar Outputs**: Flame shape morphology (`SPHERICAL`, `TRANSITIONAL`, `TEARDROP`), peak temperature ($K$), radial reaction front ($mm$), mass burning rate ($mg/s$), and soot volume fraction ($ppm$).
- **2D Spatial Temperature Heatmap**: Interactive Eulerian coordinate grid rendered on an HTML5 canvas from Member 4's `temperature_matrix` with blackbody colormap and mouse coordinate probe.
- **Discrete Time-Series Trajectory**: SVG chart displaying transient curves for temperature, radius, burn rate, and soot concentration.
- **Side-by-Side Gravity Comparator**: Interactive comparison tool rendering comparative flame geometries, delta calculations, and heatmaps between 0g and 1g.

### 5. AI Research Assistant (`/assistant`)
- **AI Combustion Diagnostic Reports**: Scientific summaries, regime classifications, confidence scores, and findings generated by Member 3's AI engine.
- **Dimensionless Scaling Gauge**:
  - **Grashof Number ($Gr$)**: Buoyancy vs. viscous forces
  - **Richardson Number ($Ri$)**: Buoyancy vs. flow shear
  - **Froude Number ($Fr$)**: Inertial vs. gravitational field
  - **Rayleigh Number ($Ra$)**: Convective heat transfer regime
- **Scientific Q&A Console**: Interactive inquiry tool answering questions on spherical symmetry, flicker vortex suppression, d²-law droplet burning, and radiative extinction limits.

### 6. Experiment History & Parameter Matrix (`/history`)
- **Archive Catalog**: Searchable and filterable table of all recorded experiments.
- **Filters**: By fuel chemical species, gravity regime (0g, partial-g, 1g), and text search.
- **Experiment Detail Modal**: Full inspection of chamber constraints, investigator credits, and notes.
- **Parameter Matrix Comparison**: Select up to 4 experiments to compare reactant configurations side-by-side in a comparative matrix.

## 4. Startup & Execution Instructions (Windows)

### Step 1: Start the FastAPI Backend

Open a PowerShell terminal in the repository root:

```powershell
# Navigate to repository root
cd "C:\Users\Srujan S\NASA-FLAME"

# Activate Python virtual environment
.\.venv\Scripts\activate

# Seed canonical NASA experiments (if not already seeded)
python database/seeds/seed_experiments.py

# Start FastAPI backend on port 8000
python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000
```

- API Base: `http://127.0.0.1:8000`
- Swagger Documentation: `http://127.0.0.1:8000/docs`
- Health Check: `http://127.0.0.1:8000/health`

### Step 2: Start the Next.js Frontend

Open a second PowerShell terminal:

```powershell
# Navigate to frontend directory
cd "C:\Users\Srujan S\NASA-FLAME\frontend"

# Production Build
npm run build

# Start Production Server on port 3000
npm run start -- -p 3000

# (Or run development server with live reload)
npm run dev
```

- Web Application: [http://localhost:3000](http://localhost:3000)
